纳瓦霍密码（Navajo Code Talkers）

> 密件册 · 1942–1945 · 太平洋战场 · 性质：真实史料 / Real record · 关联游戏：navajo-talker

说明

中文：美国海军陆战队以纳瓦霍语编制两套密码，训练纳瓦霍人担任无线电通讯员；日军始终无法破解，硫磺岛六名译电员 48 小时无差错收发 800 余条电文。

English: The U.S. Marine Corps built two codebooks on the Navajo language and trained Navajo speakers as radio operators; the Japanese never broke it — at Iwo Jima six code talkers relayed over 800 error-free messages in 48 hours.
